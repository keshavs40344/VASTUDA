Formulas, trade-offs, and cost-optimization guide

What is a token in Large Language Models (LLMs)?
A token is the basic atomic unit of text that an LLM processes. As a general rule of thumb, 1 token is roughly 4 characters or 0.75 English words. 1,000 words is approximately 1,333 tokens.
Why do completion (output) tokens cost 3 to 4 times more than prompt (input) tokens?
Input tokens can be processed in parallel using efficient matrix multiplications on GPUs (like KV cache lookups). Output tokens, however, must be generated auto-regressively one token at a time in sequential forward passes, consuming significantly more GPU compute and memory bandwidth.
How can developers reduce their monthly LLM API bill by 70% or more?
1. Use Prompt Caching (Anthropic and OpenAI offer up to 90% discounts on cached system prompts). 2. Use Model Cascading: route easy queries to lightweight models (Gemini 1.5 Flash or GPT-4o-mini) and only invoke flagship models (Claude 3.5 Sonnet) for complex reasoning. 3. Compress system prompts and prune unnecessary conversation history.
What is the difference between GPT-4o and GPT-4o-mini?
GPT-4o is OpenAI's flagship multimodal model designed for high-intelligence reasoning and coding. GPT-4o-mini is a lightweight model that is over 80% cheaper and significantly faster, making it the ideal choice for high-volume tasks like summarization, categorization, and simple extractions.
