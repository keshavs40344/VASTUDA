2. Description of the Services

VASTUDA provides a unified web discovery and browser ecosystem consisting of two distinct products:

Product 1: VASTUDA Online Search & Knowledge Platform

An independent online search destination offering:

  • Web Search: Hybrid search querying public web records and indexed content.
  • Discover: Aggregated real-time topical streams across technology, science, news, and development.
  • Research: Evidence synthesis referencing scientific publications and preprints.
  • AI Overviews: Restrained algorithmic summaries with citations linking directly to source materials.

Product 2: VASTUDA Native Browsers

Real, standalone web browser applications for Windows desktop and Android mobile devices. The native browsers load arbitrary third-party websites directly using standard system web rendering engines (Chromium WebContentsView on Windows and Android WebView on Android).
